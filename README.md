<p align="center"><b>GEOBoost is no longer developed. Its AI visibility scan now ships in Vireo Analytics.</b></p>

Vireo Analytics runs the same scan from its Search & AI tab: whether AI crawlers can reach a page, read it and cite it, with a fix for each problem. It also records which AI crawlers visit and which AI answers send you readers. Vireo Analytics Pro adds an alert when AI crawler visits drop off.

Get it at [vireowp.com](https://vireowp.com) or from the [WordPress plugin directory](https://wordpress.org/plugins/vireo-analytics/).

This repository stays up for reference and won't get further updates.
